# ParentPal

An iOS app for parents to track activities, manage schedules, and organize family life.

## Overview

ParentPal helps new and experienced parents keep track of the chaos. From feeding schedules and sleep patterns to meal planning and family events - all in one place.

## Features

### Phase 1 (Current)
- 🍼 Activity tracking (feeding, sleep, diaper changes)
- 📊 Daily summaries and basic insights
- 👶 Child profile management

### Planned
- 📸 Photo timeline with milestones
- 📅 Family calendar
- 🍽️ Meal planner with recipes
- 📍 Family-friendly event finder
- ☁️ iCloud sync across devices
- 💰 Freemium model with premium features

## Tech Stack

- **SwiftUI** - UI framework
- **SwiftData** - Local data persistence
- **iOS 17+** - Minimum deployment target
- **StoreKit 2** - In-app purchases (planned)

## Project Status

🚧 **In Active Development** - This is a learning project and portfolio piece.

Current focus: Building MVP with core activity tracking functionality.

## Development

This app is being built as a solo project to:
- Learn modern iOS development practices
- Demonstrate SwiftUI and SwiftData proficiency
- Create a useful tool for parents
- Build portfolio material

## Installation

1. Clone the repository
2. Open `ParentPal.xcodeproj` in Xcode
3. Build and run (⌘R)

No external dependencies or CocoaPods required.
